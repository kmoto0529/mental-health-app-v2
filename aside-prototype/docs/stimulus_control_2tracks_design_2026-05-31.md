## 0. 設計方針

### 0.1 なぜ2系統に分けるか

現状の汎用9ステップ（メンタル・集中・睡眠・運動・習慣・その他の6カテゴリ）は抽象的すぎてユーザーが何をすべきか掴めない問題があった。画像設計では **CBT-I（不眠症の認知行動療法）の「刺激統制」** をベースに、当社ターゲット（22-28歳キャリア初期女性）が困りがちな2大課題に絞り込む：

- **A. 睡眠刺激統制（不眠向け）**：寝つき・睡眠の質
- **B. スマホ刺激統制（スマホ依存向け）**：使用時間・反射的利用

両系統とも **「刺激（きっかけ）を変えれば行動は自然に変わる」** という共通原理に立脚。

### 0.2 共通フロー構造

```
[初回訪問]
0. 刺激統制とは？（2択分岐）
 ├─ A系統 → 睡眠ワーク 7ステップ
 └─ B系統 → スマホワーク 7ステップ

[初回訪問 7ステップ]
1. チェック（現状把握）
2. ループ可視化（5段階）
3. プラン提案（AI生成・5案）
4. プランを選ぶ（1つ選択）
5. 実施（今夜/今日）
6. 翌朝チェック
7. 週次レポート

[2回目以降 5ステップ・カセット押下で再開]
1. 翌朝チェック（再開）
2. 今日のプラン確認（続ける/変更）
3. 実施
4. 翌朝チェック
5. 効果の振り返り
```

#### 「具体的にやること」リスト

各プランごとの固定リスト：

##### プラン1: 寝室はスマホ禁止ゾーンに設定
- 寝室にスマホを持ち込まない
- 充電はリビングで行う
- 寝る1時間前はスマホを見ない

##### プラン2: 就寝前ルーティンを作る
- 寝る30分前に部屋の明かりを暗くする
- ぬるめのお風呂か温かい飲み物で体を整える
- 同じ順番（歯みがき → ストレッチ → ベッド）を毎晩繰り返す

##### プラン3: 眠れないときはベッドを出る
- 寝つけないと感じたら15-20分でベッドを離れる
- 別の部屋で静かに過ごす（読書・音楽など）
- 眠気が戻ってきたらベッドに戻る

##### プラン4: 起床時間を一定にする
- 平日も休日も同じ時間に起きる（±30分以内）
- アラームは1回で起きる
- 起きたらカーテンを開けて朝日を浴びる

##### プラン5: リラックスできる環境をつくる
- 寝室の温度を 18〜20℃ に整える
- 間接照明やアロマで落ち着く雰囲気にする
- 寝る前のカフェイン・お酒は控える

## 6. きづきタブ最上部「取り組み中のワーク」表示（新規セクション・社長指示 2026-05-31）

### 6.1 なぜ必要か

行動実験と刺激統制は **継続して取り組むコンテンツ**（数日〜数週間のサイクル）。ユーザーが毎回きづきタブを開いたとき、「今どこまで進めたか」「次に何をすべきか」を一目で把握し、ワンタップで続きから再開できる必要がある。

現状（v0.9.90）は行動実験の「⏳ あとで実施する予定」が「最近のきろく」セクションに**完了履歴と一緒に混在**しており（[index.html:11508](aside-prototype/index.html#L11508)）、進行中と完了の区別が弱い。

### 6.2 きづきタブ トップ画面の新構成

```
┌─────────────────────────────────────┐
│ [ヘッダー / ⓘ]                       │
├─────────────────────────────────────┤
│ ⏳ 取り組み中のワーク（NEW・最上部）  │  ← 進行中セッションが1件以上ある時のみ表示
│  ┌───────────────────────────┐     │
│  │ 🌙 睡眠刺激統制              │     │
│  │ 翌朝チェック待ち / 3日連続  │  › │
│  └───────────────────────────┘     │
│  ┌───────────────────────────┐     │
│  │ 🧪 行動実験                  │     │
│  │ あとで実施する予定          │  › │
│  └───────────────────────────┘     │
├─────────────────────────────────────┤
│ [4ワーク一覧（既存）]                │

└─────────────────────────────────────┘
```

### 6.3 「取り組み中のワーク」表示仕様

#### 6.3.1 表示条件

- 進行中セッションが**1件以上**ある時のみセクション表示
- 0件なら**セクションごと非表示**（高さも消す）

#### 6.3.2 対象ワークと判定ロジック

| ワーク種別 | 進行中判定 |
|---|---|
| **行動実験** | `state.behaviorExperiments[]` のうち `status === 'pending'`（あとで実施予定）または `status === 'in-progress'`（実施はしたが振り返り未完了） |
| **刺激統制（睡眠）** | `state.stimulusControlSessions[]` のうち `track === 'sleep'` かつ `status === 'active'`（最終checkin から7日以内） |
| **刺激統制（スマホ）** | `state.stimulusControlSessions[]` のうち `track === 'phone'` かつ `status === 'active'`（最終checkin から7日以内） |

> **7日基準の根拠**: 8日以上 checkin が無いセッションは「離脱」とみなし `status: 'paused'` に変更。最近のきろく側に履歴として残す。

#### 6.3.3 カード表示内容

各進行中セッションを縦並びで表示（最大3枚想定：行動実験1 + 睡眠1 + スマホ1）。

| 要素 | 内容 | 例 |
|---|---|---|
| アイコン + チップ | ワーク種別 | 🌙 睡眠刺激統制 / 📱 スマホ刺激統制 / 🧪 行動実験 |
| メインライン | 現在のステップ・状態 | `翌朝チェック待ち` / `あとで実施する予定` / `Step 3/5 実施中` |
| サブライン | 連続日数 or 最終アクション日 | `3日連続` / `最終: 2日前` |
| 矢印 | `›` | クリック可能なシグナル |

#### 6.3.4 カードのタイトル文言（ステップ別）

##### 行動実験
| status | メインライン |
|---|---|
| pending | `⏳ あとで実施する予定` |
| in-progress | `🧪 実施したら振り返りへ` |

##### 刺激統制（系統共通・ステップ別動的文言）
| 現在ステップ | メインライン |
|---|---|
| Step 5 実施直後（翌朝チェック未完了） | `🌙 翌朝チェック待ち` / `📱 翌朝チェック待ち` |
| Step 6 翌朝チェック完了直後 | `📊 今日のプラン確認` |
| Step 7（週次レポート未閲覧） | `🎉 1週間レポートが見られます` |
| 再訪フロー Step 1 待ち | `🌅 昨日の振り返りを記録しよう` |

### 6.4 クリック時の遷移先

| ワーク種別・状態 | 遷移先 |
|---|---|
| 行動実験 `pending` | 行動実験の Step 4「実施画面」へ |
| 行動実験 `in-progress` | 行動実験の Step 5「振り返り入力」へ |
| 刺激統制 翌朝チェック未完了 | 該当系統の Step 6「翌朝チェック」画面 |
| 刺激統制 今日のプラン確認待ち | 再訪フロー Step 2「今日のプラン確認」画面 |
| 刺激統制 週次レポート未閲覧 | 該当系統の Step 7「週次レポート」画面 |

### 6.5 「最近のきろく」セクションとの関係（重複回避）

- 取り組み中（active / pending / in-progress）は **「取り組み中のワーク」セクションにのみ表示**
- 完了済み（completed / paused）は **「最近のきろく」セクションにのみ表示**
- 既存の `getKizukiRecentRecords()`（[index.html:11477](aside-prototype/index.html#L11477)）から進行中レコードを除外するフィルタを追加

### 6.6 セクション見出しデザイン（既存スタイル踏襲）

- ヘッダー: `<div class="kizuki-active-title">⏳ 取り組み中のワーク</div>`
- カード: 既存の `kizuki-recent-row` を流用（色味とアクセントだけ active 系に差し替え）
- アクセント色: 進行中＝暖色（例: `#D77B5B`）、完了履歴＝中性色（既存維持）

### 6.7 ゼロ件時の挙動

- 進行中セッションが0件のときは **セクション全体を非表示**
- 「あなたが今取り組み中のワークはありません」のような空状態メッセージは出さない（ノイズになる）
- → 自然と「4ワーク一覧」が最上部に見える状態に戻る
