# きづきワーク アイコン差し替え

このフォルダに PNG を置くと、きづきタブのワークカード左側のアイコンが自動的に差し替わります。
PNG が存在しないワークは絵文字（KIZUKI_WORKS の `icon` プロパティ）にフォールバックします。

## ファイル名（拡張子は必ず .png）

| ワーク | ファイル名 | 推奨色味 |
|---|---|---|
| モヤモヤの原因を深掘りする（下向き矢印法） | `downward-arrow.png` | 青系 |
| 考えを確かめてみる（行動実験） | `behavior-experiment.png` | 緑系 |
| 考え方のクセに気づく（認知の歪みテスト） | `distortion.png` | ピンク系 |
| 頭の中を整理する（コラム法） | `column-method.png` | 黄〜オレンジ系 |
| 環境を整えてラクになる（刺激統制） | `stimulus-control.png` | 紫系 |

## 推奨スペック

- **サイズ**: 256×256 px 以上の正方形（カード内では 64×64 px の円形コンテナに contain で収まる）
- **背景**: 透過 PNG 推奨（円形の背景色は CSS 側で `iconBg` カラーを敷くため）
  - 円ごと描いた PNG を入れても問題なし（その場合は CSS の円形コンテナの上に乗ります）
- **形式**: PNG（アルファチャネル対応）

## 反映方法

1. PNG をこのフォルダに上記ファイル名で保存
2. `service-worker.js` の `CACHE_VERSION` をバンプ
3. PWA インストール済みの場合はホームから一度削除→再追加で確実に反映
